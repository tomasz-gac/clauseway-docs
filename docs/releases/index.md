# Releases

Clauseway has not cut its first release yet: the whole stack currently
develops on a single `0.1.0-SNAPSHOT` line.

## Upcoming: 0.1.0

The first release will bundle, across the stack:

- the relational engine: unification, constraint stores, tabling with
  constraint-aware caching, weighted inference;
- typed finite-domain arithmetic with capability seats — ints, longs,
  big integers, exact decimals, dates and instants — with open/closed
  interval endpoints and operators that compute any position from the
  others;
- the data boundary: SQL and in-memory sources, constraint pushdown,
  column codecs, transactions certifying their reads;
- the lending-library example application.

Release notes will appear here when the tag is cut.
