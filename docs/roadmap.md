# Roadmap

The near-term line, in no promised order. Each item is a named door:
scoped, with its trigger understood, opened when the need is real.

- **Cut and committed choice** — a real `once`/`ifte`, subsuming the
  committed-choice combinators.
- **Public API documentation** — javadoc coverage for the user-facing
  surfaces.
- **Directed-rounding intervals** — sound bounds propagation for dense
  numeric types beyond exact arithmetic.
- **Canonical identity** — first-class canonicalization for types whose
  equality needs a representative.
- **Semiring-weighted inference, later phases** — counting,
  probability, provenance on the one engine.
- **Dependency and release modernization** — from snapshots to a
  release train.
